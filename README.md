# ✅ 개인용 할 일 관리 앱 (Personal To-Do App)

복잡한 백엔드 서버 없이 웹 브라우저의 로컬 스토리지를 활용하여 데이터를 저장하는 가볍고 빠른 할 일 관리(To-Do) 웹 애플리케이션입니다.

## 🛠 Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Storage:** Browser LocalStorage

## ✨ Key Features
- **할 일 관리(CRUD):** 항목 추가, 삭제, 완료(취소선) 처리 기능
- **진행률 대시보드:** 전체 및 카테고리별 달성률을 프로그레스 바와 함께 시각적으로 제공
- **카테고리 분류:** 업무(파란색), 개인(초록색), 공부(보라색) 태그 및 필터링 기능
- **인라인 편집:** 항목 텍스트를 더블클릭하여 내용을 즉시 수정
- **드래그 앤 드롭:** 마우스로 항목을 끌어서 원하는 대로 순서 변경
- **다크 모드:** 눈이 편안한 다크 모드 토글 및 브라우저 환경 기억
- **데이터 백업:** 전체 할 일 데이터를 JSON 파일로 내보내거나 가져오기 기능
- **키보드 단축키:** `Alt + N` (새 할 일 입력), `Alt + 1~4` (필터 전환) 지원

## 🚀 How to Run
- 별도의 설치 과정 없이 `index.html` 파일을 크롬, 엣지 등 웹 브라우저에서 열면 바로 실행됩니다.
